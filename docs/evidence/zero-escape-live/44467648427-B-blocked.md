## 实际失败点

1. `S_PROJECTS_STATE_PAT` 在 orchestrator job 内为 **空**（未配置仓库 secret）。
2. 回退 `GO_GITHUB_RUN_TOKEN` 存在，但 `gh api user` → **HTTP 401 Bad credentials**（该 secret 为 Factory/网关 API key，**不能**作为 `gh` GitHub REST PAT）。

在仓库 Actions secrets 配置其一（值均为 **GitHub classic PAT**，`repo` + `issues` 写权限，非 `GITHUB_TOKEN`）：

1. **`I8_TEAM_TRIGGER_PAT`**（推荐，专用于 I8 orchestrator 发 `@team-droid`）
2. 或 **`PROJECTS_STATE_PAT`**（若已在生产使用且对 workflow 可见）

配置后向 `main` 再次合并 `triggers/B.scene` marker → orchestrator 将重跑场景 B。
