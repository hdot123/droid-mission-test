**480s 套壳**

- validate 步在未命中 I8 标题时 **不传** `--droid-wall-override-sec`，墙内 validator 为 480 → **GNU 硬顶 480s**。

**120s 预留**

- 机制是 **分槽**：droid 最多 480s，采认相关步单独占时；不是在同一会话里从 600 做减法。
- adopt 步：`timeout-minutes: 2`（=120s GitHub step 上限），并 echo `adopt_reserve_sec`；**未**用 `ADOPT_RESERVE_SEC` 动态设置 step `timeout-minutes`（墙值变更时 step 上限不会跟墙联动）。
- validate **job** 仍为 `timeout-minutes: 15`（未改为 12）；`job_wall_min: 12` 仅存在于墙配置 + lint 代数检查（`assert_validator_job_budget(..., job_timeout_min=15)`）。

**判定**：非 I8 工单下验收 droid **不能再吃满 600s**（GNU 480）；120s 在设计与 lint 包络内成立，但采认步 120s 与墙字段 **未程序绑定**，属残余。
