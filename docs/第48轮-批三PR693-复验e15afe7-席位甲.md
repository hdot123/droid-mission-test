## 3. 缺口三：常态路径不再静默回到 600s；job 12 vs GHA 15 分工

### 3.1 去掉 validator 600 静默兜底

`70a0238` 上 `droid_wall_sec` 曾为 `role_budget(...).get("droid_wall_sec", 600)`。

`e15afe7` 改为合并后 **无字段则 `ValueError`**，常态依赖 `role_budget` 与 `default_budgets()` 合并（validator 基座 **480**）：

```python
# scripts/team/budget_resolve.py
rb = role_budget(wall, role)
if "droid_wall_sec" not in rb:
    raise ValueError(...)
return int(rb["droid_wall_sec"])
```

`validator_session_budget` 同样要求墙合并后显式键，不再 `.get(..., 480/120)` 与 600 混用。

**测试：** `test_validator_droid_wall_not_600_when_role_stripped` — 删墙上 `droid_wall_sec` 或整段 `validator` 角色后仍得 **480**（来自 `default_budgets` 合并）。

**I8 显式 override：** validate 步仍仅在 `[I8] API墙活验 A/D` 标题下传 `--droid-wall-override-sec ${VALIDATOR_DROID_TIMEOUT_SECONDS:-600}`；**非常态路径**，保留合理。

### 3.2 `job_wall_min: 12` vs GitHub `timeout-minutes: 15`

| 项 | 值 / 机制 |
|----|-----------|
| 墙契约 | `default_budgets().roles.validator.job_wall_min == 12` |
| GHA job | `validate` / `validate2` 仍为 **`timeout-minutes: 15`**（未改 12） |
| 文档 | `budget_resolve.py` 注释说明 12 为契约分片、15 为平台包络 |
| lint | `lint_workflow_budgets.py` 断言 `vmin == 12` 且 validate job chunk 含 `timeout-minutes: 15` |

**判定：闭合。**
