## 已查实（证据链）

### 1. W-8 根因与 PR 修复

- **代码路径（main）**：`project_state_write.py` `fields = json.loads(fr.stdout or "[]")` 后直接 `pick_status_option(fields, …)`（PR 前 `git show main:scripts/team/project_state_write.py`）。
- **本地复现**（PR 分支 HEAD，`tests/fixtures/gh_project/field_list_envelope.json`）：

```text
W8 main-path: AttributeError 'str' object has no attribute 'get'
W8 fixed: ('PVTF_lACO', 'OPTION_pass')
```

  未拆盒时对 dict 迭代键名，`f.get` 在 str 上失败；拆盒后 `pick_status_option` 正常。

- **契约测试**：`tests/test_gh_project_parse_contract.py::test_w8_bare_dict_breaks_pick_status_without_parse`（信封直接传入 → `AttributeError`）；`test_w8_pick_status_after_parse` 绿。

### 2. W-1 信封拆盒（#654 延续 + 模块下沉）

- #654 已在 `foreman_run_lib.parse_project_item_list` 读 `payload["items"]`；PR 将实现迁入 `gh_project_parse.unwrap_item_list_envelope`，别名保留。
- **复跑**：`pytest tests/test_foreman_wall_failure_paths.py::test_w1_*` 与 `test_gh_project_parse_contract.py::test_w1_item_list_envelope_fixture` 通过。

### 3. 分页策略（是否为「只抬高盖盖」）

- **实现**（`gh_project_parse.fetch_project_items`）：首次 `--limit min(page_size, 10000)`（默认 100）；若 `totalCount` 为 int 且 `len(items) < totalCount`，再调用 `call_item_list(min(totalCount, 10000))`；若仍截断且达上限则 `RuntimeError`（fail-closed）。
- **不是**：仓库内无 `--after` / page 游标循环，**不能**声称覆盖所有 GitHub API 信封或所有 gh 分页形态。
- **是**：相对 main 固定 `--limit 200` 单次，在 **提供 `totalCount` 且 gh 在高 limit 下返回全集** 的前提下，消除「total 大于首包仍只扫 200」类假阴性。
- **契约证据**：`test_item_list_pagination_refetch` 断言 `calls == [100, 250]` 且 `len(items)==250`。

### 4. 收口与 lint
