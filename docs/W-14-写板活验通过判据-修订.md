## 修订判据（活验通过）

以下**三件齐备**即算 **写板活验通过**：

1. **运行窗内**：对位工单 run 的 Actions 时间窗内发生写板相关步骤（assemble `Write Projects board via PAT` 已执行且可对照日志）。
2. **PAT 持有人身份的写板变更**：Projects #33 字段历史（或等价仓外旁证）出现与 `project_state_enum` 一致的 Status（或其它映射字段）变更；时间线演员为 **PAT 所属用户** 即满足本项，**不要求** `github-actions[bot]`。
3. **墙内** `closeout.project_state_written=true`：`foreman-run.json` 同窗内该字段为 true，且与 assemble 写板步成功、`gh project item-edit` 返回 0 对齐。

### `project_state_written=true` 的对齐要求

- 仍须与 assemble 写板步成功、墙工件 diff（写板前后 `closeout.project_state_*`）**同 run** 对齐。
- 活验旁证仍取 Actions 日志（`project state -> …`）与 Projects 字段历史；**仅取消**「演员必须是 bot」的旧要求。

### 边缘情形（P2，不进 W-14 主罪）

- **PAT 缺失未落账 + 旧 closeout 残留**：`PROJECTS_STATE_PAT` 空时 `project_state_write.py` 直接退出、不落账，墙上可能出现上一 run 残留；用活验 checklist 排除，不作为 W-14「closeout 误报」主路径定罪依据。
