### 规则原文要点（`main`）

`scripts/team/lint_workflow_wall_exits.py`（`main`）主要检查：

1. 每个 `CHAIN_EXIT_OWNERS` 座位存在带 `if: always()` 的 `wall_sync_job` / `assemble_chain_facts --assemble-exit` 步（`wall_sync_always_ok`）。  
2. 若干 job 须 `Upload foreman-run` 且 `always()`（`upload_always_ok`）。  
3. merge job 在上游 `cancelled` 时仍可跑（`merge_jobs_admit_upstream_cancelled`）。  
4. 写账步禁止 `always() && !cancelled()`（`wall_accounting_steps_no_cancelled`）。  
5. lead 禁止仅 success 落账（`lead_not_success_only`）。

**盲区（相对 issue 普查面）**：

| 形态 | main lint 是否覆盖 |
|---|---|
| derive 与 chain sync 同 `run:` | **未覆盖**（函数仅存在于未合并分支 `origin/cursor/w11-derive-chain-decouple-73dd`） |
| `merge_worker_deltas` 与 `wall_sync_job` 同 `run:` | **未覆盖** |
| 写账为 `post_comment_hard --wall-patch` 且前有可失败命令 | **未覆盖**（仅扫 markers 子集） |
| 步内 `if` 分支后再写账 | **未覆盖**（静态不解析 shell 分支） |
| 子脚本内部 `save_wall` | **未覆盖**（只看 workflow 字面量） |

`lint_workflow_foreman.py`：禁止 `compute_validate_conclusion.py ... || true`（`FORBIDDEN` 第 19 项），**不**禁止同 step 串联。
