## What was requested

Process card #865 under work order #851 (round-55 concurrent D card): implement the
A1Z26 letter-index codec as two new files only — `a1z26.py` and

## What I did

- Created `a1z26.py`:
  - `a1z26_encode(text: str) -> str`: only uppercase A–Z with single-space word
    separators; letters → 1–26; indices joined with `-` within a word, words with a
    single space; `""` → `""`.
  - `a1z26_decode(code: str) -> str`: inverse; indices must be 1–26, no leading
    zeros; separator form symmetric with encode; `""` → `""`.
  - Input conventions: encode raises `ValueError` on lowercase/digits/consecutive or
    leading/trailing spaces; decode raises `ValueError` on out-of-range index /
    leading zero / empty segment / space inside a word; non-`str` raises
    `TypeError` for both functions.
- Created `tests/test_a1z26.py` with a test case for every acceptance point in the
  card:
  - encode: `""→""`, `"A"→"1"`, `"Z"→"26"`, `"ABC"→"1-2-3"`,
    `"HELLO"→"8-5-12-12-15"`, `"HELLO WORLD"→"8-5-12-12-15 23-15-18-12-4"`.
  - decode: `""→""`, `"1-2-3"→"ABC"`,
    `"8-5-12-12-15 23-15-18-12-4"→"HELLO WORLD"`, `"26-1"→"ZA"`.
  - round-trip for `"PYTHON"`, `"A B C"`, `"ZZZ AAA"`.
  - `ValueError`: encode on `"hello"`, `"A1"`, `"A  B"`, `" A"`; decode on `"0"`,
    `"27"`, `"01"`, `"1--2"`, `"1- 2"`.
  - `TypeError`: `a1z26_encode(None)` (and `a1z26_decode(None)`).
