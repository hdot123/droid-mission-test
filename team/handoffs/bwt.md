Spec highlights (pinned verbatim from the card):

- `bwt_encode(s: str) -> tuple[str, int]`: sort all n cyclic rotations ascending by
  `(rotation string, original offset)`; the tie-break for equal rotation strings
  (periodic strings) is explicitly the smaller offset first — **not** left to sort
  stability. Returns (last column, row of the offset-0 rotation).
- `bwt_decode(last_col: str, index: int) -> str`: inverse transform (LF-mapping
  iteration).
- Validation: empty string (encode and decode) → ValueError; index out of range
  (`< 0` or `>= len(last_col)`) → ValueError; non-str s/last_col, non-int index
  (bool counts as non-int) → TypeError.

## What I did

Created `bwt.py`:

- `bwt_encode` builds `sorted(((s[i:] + s[:i], i) ...), key=(rotation, offset))` —
  the tie-break key is explicit in the sort key, so periodic strings
  ("abab", "aaaa") order by ascending offset regardless of stability.
  Primary index located by scanning for `offset == 0`.
- `bwt_decode` validates type/emptiness/index first, then decodes with the
  standard LF-mapping: character counts → column start offsets → per-row rank,
  iterating `row = starts[c] + rank[row]` from `index`, collecting and reversing.

Created `tests/test_bwt.py` with a case for every acceptance item:

- Exact examples: `("banana" → ("nnbaaa", 3))`, decode round trip,
  `("mississippi" → ("pssmipissii", 4))`, `("abab" → ("bbaa", 0))`,
  `("aaaa" → ("aaaa", 0))`, `("a" → ("a", 0))`.
- Property tests on a seeded corpus (seed 590063; lengths 1–14, alphabets
  {a, ab, abc, abcd} plus pinned periodic and single-letter strings): encode
  agrees with an independent rotation-doubling-style reference (rank doubling
  by pairing halves of cyclic windows, tie-break on offset), `decode(encode(s)) == s`,
  and decode agrees with a naive prepend-and-sort table decoder.
- Explicit tie-break test pinning the periodic cases against the doubling reference.
- ValueError: `bwt_encode("")`, `bwt_decode("", 0)`, `bwt_decode("abc", 3)`,
  `bwt_decode("abc", -1)`.
- TypeError: `bwt_encode(b"ab")`, `bwt_encode(12)`, `bwt_decode(9, 0)`,
  `bwt_decode("abc", 1.0)`, plus `bwt_decode("abc", True)` (bool index).
